# 标泵控制程序

本程序是一个基于 `Python` 的 GUI 应用程序，用于通过串口通信与标泵进行数据交互，同时实现酸油比的手动控制和 PID 控制功能。程序通过 `Tkinter` 构建图形界面，结合 `matplotlib` 进行数据绘图，并支持实时显示泵流量和标泵操作。

---

## 功能描述

### 主要功能
1. **手动控制**：用户可以手动设定泵流量，并实时查看当前泵的流量。
2. **PID 控制**：根据设置的目标酸油比，自动调整泵的流量以达到设定目标。
3. **实时数据显示**：
   - 泵的当前流量。
   - 实时标泵数据。
4. **数据绘图**：实时绘制酸油比与时间的关系。
5. **定时功能**：秒表计时支持。

---

## 环境要求

### 系统要求
- Windows 操作系统
- 已正确连接的标泵设备，且分配了串口（如 `COM3` 和 `COM4`）。

### 软件依赖
- Python 3.8+
- 必需安装以下模块：
  ```bash
  pip install pyserial matplotlib
  ```

---

## 使用指南

### 运行程序
1. 确保设备连接并设置正确的串口通信参数。
2. 运行程序：
   ```bash
   python pump_calibrate.py
   ```
3. 主界面将显示以下主要功能按钮：
   - **获取数据**：通过串口获取实时泵的数据。
   - **标泵**：计算当前标泵值。
   - **手动控制**：用户可手动调整泵的流量。
   - **PID 控制**：启动 PID 自动控制功能。
   - **导出进料比**：停止 PID 控制，并导出当前进料比。

### 设置参数
- **目标酸油比**：在主界面中输入目标值（如 `1.2`）。
- **手动流量控制**：在对应文本框中输入期望的泵流量值。

## 文件说明

### 主代码结构
- **类 `PC`**：
  - 实现程序主界面及交互逻辑。
- **类 `PID`**：
  - 实现 PID 控制算法（支持位置式和增量式）。
- **函数 `testPid()`**：
  - 调用 `PID` 控制器并定期获取和调整泵的流量。
- **函数 `flux_get()` & `flux_set()`**：
  - 获取和设置泵的当前流量。
- **函数 `scale_display()`**：
  - 获取标泵设备的当前重量值。

### 图形界面布局
通过 `Tkinter` 实现，包含：
- 标签（`Label`）：显示实时数据和提示信息。
- 输入框（`Entry`）：允许用户输入目标值。
- 按钮（`Button`）：触发不同功能。

---

## 注意事项

1. **串口配置**：
   - 串口通信需正确设置设备的波特率及端口号，默认使用 `COM3` 和 `COM4`。
2. **实时绘图**：
   - 使用 `matplotlib` 的交互模式，实时更新数据图表。
3. **异常处理**：
   - 如果泵未能正确响应或通信失败，程序将提示错误信息。
